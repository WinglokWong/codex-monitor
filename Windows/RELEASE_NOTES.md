# Codex Monitor for Windows v1.2.0-beta.1

首个 Windows 10/11 x64 预览版。macOS 正式版 v1.1.1 保持不变。

- 原生 WPF 悬浮面板，独立任务栏图标与托盘入口，可拖动、置顶、隐藏和恢复，保存窗口位置。
- 读取 Windows 本机 Codex CLI 的登录账号，显示脱敏邮箱、套餐、剩余周额度及北京时间重置倒计时。
- 每秒显示 CPU、物理内存及物理 Ethernet/Wi-Fi 网卡的上传、下载速率。
- 保留正常账号通知处理、最终身份核对、安全错误详情，以及 3 秒/8 秒两次有限重试。
- 提供 CLI 自动查找和手动选择，不包含发布者的登录凭据。

## 下载与使用

下载 `Codex-Monitor-1.2.0-beta.1-windows-x64.zip`，完整解压后运行 `CodexMonitor.exe`。包内包含 .NET 运行时，不需要另装 .NET，不要求管理员权限。查询额度需要先在 Windows 上安装并登录 Codex CLI；系统监控可独立使用。

Windows 10 建议使用 22H2，或使用 Windows 11 x64。关闭窗口会隐藏到托盘；双击托盘图标、重新启动程序或托盘菜单可恢复面板。从托盘或面板菜单选择「退出监控」才能结束程序。

发布附件包含 SHA-256 校验文件。本版本未进行 Windows 代码签名，首次运行可能出现 SmartScreen 提示；请核对下载来源及校验值，按系统提供的正常流程处理。

## 验证范围

本次移植在 Mac 上开发及交叉编译，通过 GitHub 的 Windows 构建环境运行自动测试、Windows 原生采集冒烟测试和 WPF 界面渲染验证。协议测试使用合成账号，不依赖或上传真实 Codex 登录凭据。

Windows 构建环境不能替代 Windows 10/11 客户端实机验证。不同 DPI、多显示器、托盘和网卡驱动组合仍需实际机器反馈，因此先作为预览版发布。超过 64 个逻辑处理器时 CPU 明确标记为当前处理器组；虚拟机可能没有可识别的物理网卡。

这是独立第三方工具，与 OpenAI 没有官方关联。详见仓库中的 `Windows/README.md`。
