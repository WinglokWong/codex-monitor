# Codex Monitor for Windows v1.2.0-beta.2

Windows 10/11 x64 预览版新增账号与周额度的独立刷新间隔，与 macOS v1.2.0 的设置方式一致。

- 面板右上角「… → 查询间隔」提供「账号查询」和「周额度查询」两个字段，默认均为 1 分钟，只接受 1–10080 的整数分钟。
- 保存后按新设置安排后续自动刷新，重启后保留。账号定时刷新只读取账号信息；周额度查询仍在读取额度前后额外核对身份。启动、手动刷新和重试可能触发额外查询，两类查询串行执行。
- 账号单独刷新发现身份变化时，立即清空旧额度，等待下一次周额度刷新或手动刷新成功后再显示新额度。
- CPU、物理内存、网速及倒计时仍每秒更新。保留安全错误详情和 3 秒／8 秒两次有限重试，失败时继续隐藏旧账号数据。

保留任务栏与托盘入口、窗口位置和置顶设置、CLI 自动查找及手动选择。监控读取本机 Codex CLI 账户，不包含发布者的登录凭据。

## 下载与使用

从 [v1.2.0-beta.2 发布页](https://github.com/WinglokWong/codex-monitor/releases/tag/v1.2.0-beta.2) 下载 `Codex-Monitor-1.2.0-beta.2-windows-x64.zip`，完整解压后运行 `CodexMonitor.exe`。包内包含 .NET 运行时，不需要另装 .NET，不要求管理员权限。查询额度需要先在 Windows 上安装并登录 Codex CLI；系统监控可独立使用。

Windows 10 建议使用 22H2，或使用 Windows 11 x64。关闭窗口会隐藏到托盘；双击托盘图标、重新启动程序或托盘菜单可恢复面板。从托盘或面板菜单选择「退出监控」才能结束程序。

升级前先退出旧版，再替换解压目录中的程序文件。现有窗口与 CLI 设置会保留，两项新刷新间隔默认均为 1 分钟。

发布附件包含 SHA-256 校验文件。本版本未进行 Windows 代码签名，首次运行可能出现 SmartScreen 提示；请核对下载来源及校验值，按系统提供的正常流程处理。

## 验证范围

Windows 版在 Mac 上开发及交叉编译，验证流程包括 GitHub Windows 构建环境中的自动测试、Windows 原生采集冒烟测试和 WPF 界面渲染；具体结果见发布页。协议测试使用合成账号，不依赖或上传真实 Codex 登录凭据。

Windows 构建环境不能替代 Windows 10/11 客户端实机验证。不同 DPI、多显示器、托盘和网卡驱动组合仍需实际机器反馈，因此先作为预览版发布。超过 64 个逻辑处理器时 CPU 明确标记为当前处理器组；虚拟机可能没有可识别的物理网卡。

这是独立第三方工具，与 OpenAI 没有官方关联。详见仓库中的 `Windows/README.md`。
